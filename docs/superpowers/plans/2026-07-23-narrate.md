# Local Narration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Windows-local `narrate` mode that turns an approved text or
`script-draft` Markdown script into VOICEVOX utterance WAVs, one concatenated
narration WAV, synchronized SRT/VTT, and an optional review MP4 without
changing source media or applying anything to Resolve.

**Architecture:** Add a focused `minoru_studio.narrate` package beside the
existing `transcribe` and `script_draft` packages. Pure script/timing modules
own deterministic transformations, a standard-library loopback client owns
the VOICEVOX contract, a media module owns FFmpeg/FFprobe boundaries, and a
service composes them through the existing resumable `JobStore`. CLI and Tk
adapters remain thin and invoke the same request/service API.

**Tech Stack:** Python 3.12, `http.client`, existing `JobStore`, FFmpeg,
FFprobe, Tkinter, pytest; no new Python runtime dependency.

## Global Constraints

- Windows only; do not introduce a non-Windows target.
- The only HTTP destination is literal `127.0.0.1:50021`; reject redirects,
  use finite timeouts, and never follow Engine-supplied URLs.
- Resolve, cloud TTS, OpenAI APIs, automatic VOICEVOX install/start, script
  rewriting, multiple speakers, and original-audio mixing are out of scope.
- Resolve speaker `ずんだもん` / style `ノーマル` by exact live names; never
  hard-code the currently observed style ID `2`.
- Persist speech speed `1.0`, inter-utterance silence `300 ms`, maximum
  utterance length `60` Unicode code points, and preview `false` unless asked.
- Fingerprint both the video and script, copy only the script into `inputs/`,
  and never modify or delete either original.
- Accumulate FFprobe decimal-second measurements before half-up conversion of
  cue boundaries to integer milliseconds; never sum independently rounded
  utterance durations.
- Publish final outputs create-only. A changed/tampered successful output is a
  stable output-validation failure that requires a new suffixed job.
- Logs and errors must not contain script text, utterance text, VOICEVOX query
  JSON, response audio, or raw external stderr.
- Preserve current `beat-sync`, `transcribe`, `script-draft`, renumbering, and
  Resolve-adapter behavior.
- Per user direction, do deterministic mechanical tests in this phase but
  defer real VOICEVOX listening, real preview, and Resolve acceptance to the
  final consolidated test phase. Do not promote `narrate` as accepted in the
  README before that phase.

## Sol review boundaries and audit points

**Allowed implementation scope:** `src/minoru_studio/narrate/`, its matching
`tests/narrate/`, mode registration in `jobs/model.py` and `cli.py`, launcher
wiring in `gui.py`, focused regression tests, `docs/agent-handoff.md`, and this
phase's existing spec/plan. A small reuse-oriented change to a shared helper is
allowed only when its existing contracts remain unchanged and its regression
tests are extended.

**Acceptance criteria:** create/resume exit contracts work; two unchanged
inputs are required; only approved Markdown narration fields are spoken; every
utterance is at most 60 code points; exact speaker/style resolution precedes
synthesis; audio/subtitle timing is derived from measured WAVs; 300 ms gaps are
present; the artifact set is exact; preview excludes original audio; duration
overrun succeeds with a content-free warning; cancellation/resume and
create-only output safety are durable.

**Mechanical gates:** focused narrate, job-model, CLI, GUI-controller,
settings, redaction, process, and timebase tests; then the full pytest suite;
then `narrate --help` and `doctor --json`. Expected result is exit `0` for every
gate, with `doctor` still healthy and no real Engine/network call in pytest.

**Residual risks held for consolidated acceptance:** actual VOICEVOX 0.25.2
WAV shape and audible speaker identity, FFmpeg concat behavior on real Windows
paths, Japanese font rendering, long-narration final-frame extension, and
human subtitle/audio synchronization.

**Final independent audit:** required once, after the final implementation
diff and all mechanical gates. It must use only this checklist, the final diff,
summarized gate results, and unresolved risks; it must not rediscover the
entire repository or rerun real acceptance.
